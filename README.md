# StokTakipUygulamasi

Kısaca: Kullanıcıların stoklarını takip edebildiği, CRUD operasyonları ile yönetilebilen, rol-tabanlı erişim sistemi olan bir uygulama.

---

## Özellikler  
- Kullanıcı yönetimi (kayıt, giriş, roller)  
- Stok kartı oluşturma, listeleme, güncelleme, silme  
- Kullanıcı bazlı yetkilendirme (admin / normal kullanıcı)  
- Veritabanı yönetimi ve ilişkisel modelleme  
- REST API endpoint’leri & frontend arayüzü (varsa)  
- Temiz katmanlı mimari: Controller → Service → Repository → Model

---

## Kullanılan Teknolojiler  
- **Backend:** C# (.NET Core)  
- **Veritabanı:** PostgreSQL / SQL Server (hangiysa)  
- **ORM:** Entity Framework / Dapper (hangi kullanıldıysa)  
- **Frontend:** HTML / CSS / JavaScript (veya React)  
- **Araçlar:** Git, Visual Studio, Postman / Swagger
